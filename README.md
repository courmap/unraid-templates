# Courmap Unraid templates

Unraid Community Applications templates for [Courmap](https://courmap.com), maintained by Xwolv.

Currently one template: **Courmap Proxy**, an indexer proxy that makes anime releases import into Sonarr as the right episode. Releases it is unsure about pass through unchanged.

## Install

Once the repository is listed in Community Applications:

1. Open the **Apps** tab in Unraid.
2. Search for **Courmap Proxy** and click **Install**.
3. Fill in your Sonarr URL and API key, and at least one indexer URL, then click **Apply**.

## Docs

Setup guide: https://courmap.com/getting-started/sonarr/. Full guide, including Unraid: https://courmap.com/sonarr/. Issues: https://github.com/courmap/courmap/issues.
